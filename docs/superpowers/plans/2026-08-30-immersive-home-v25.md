# Study Hub Immersive Home V25 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the V24 Study Hub homepage more cinematic, readable and physically convincing on desktop and mobile, including authored approach/read/release direction, weighted depth interaction, one local CC0 hero prop, a late crash zoom into Paths, and a reversible Home ↔ Paths handoff.

**Architecture:** Preserve the six semantic Three.js stations and the V24 route/render structure. Add a pure director controller above the existing camera/lighting/parallax systems, upgrade station transfers to authored cubic curves, drive screen/caption presentation from director read state, load one local CC0 lamp with a procedural fallback, and extend the final exit with pre-crash/crash/screen-lock phases before the existing shared Paths surface.

**Tech Stack:** Vanilla ES modules, Three.js 0.185.1 vendored locally, CanvasTexture screen UI, CSS, Node `node:test`, GitHub Pages.

Use `timeline.sample(p).stationId` to select the semantic station; do not use `Array.find()` across overlapping shot windows.

```js
export function createDirectorController({ timeline, layout = "desktop" } = {}) {
  const windows = timeline.stationWindows();
  const byId = new Map(windows.map(item => [item.stationId, item]));
  const clamp01 = value => Math.min(1, Math.max(0, Number(value) || 0));
  const smooth = value => { const t = clamp01(value); return t * t * (3 - 2 * t); };

  function sample(progress, { scrollVelocity = 0 } = {}) {
    const p = clamp01(progress);
    const stationId = timeline.sample(p).stationId;
    const window = byId.get(stationId) ?? windows.at(-1);
    let phase;
    let phaseProgress;
    let readStrength;
    if (p < window.readStart) {
      phase = "approach";
      phaseProgress = clamp01((p - window.enter) / Math.max(.0001, window.readStart - window.enter));
      readStrength = smooth(phaseProgress);
    } else if (p <= window.readEnd) {
      phase = "read";
      phaseProgress = clamp01((p - window.readStart) / Math.max(.0001, window.readEnd - window.readStart));
      readStrength = 1;
    } else {
      phase = "release";
      phaseProgress = clamp01((p - window.readEnd) / Math.max(.0001, window.releaseEnd - window.readEnd));
      readStrength = 1 - smooth(phaseProgress);
    }
    const velocity = Math.min(6, Math.abs(Number(scrollVelocity) || 0));
    const velocityScale = Math.max(.3, 1 - velocity / 8);
    return {
      stationId,
      phase,
      phaseProgress,
      readStrength,
      captionStrength: phase === "read" ? .45 : .9,
      motionScale: Math.max(.55, velocityScale),
      parallaxScale: velocityScale * (phase === "read" ? .65 : 1),
      lightingScale: phase === "read" ? .9 : 1,
      layout
    };
  }
  return { sample };
}
```

function cubicPoint(a, b, c, d, t) {
